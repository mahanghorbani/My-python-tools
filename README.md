# Market Pulse Monitor
A lightweight Python-based tool to monitor real-time asset prices using Binance API.

## Features
- Real-time data fetching
- Lightweight and dependency-minimized
- Easy to extend for other assets

## Usage
1. Clone the repo: `git clone https://github.com/mahanghorbani/My-python-tools`
2. Install requirements: `pip install requests`
3. Run: `python main.py`
